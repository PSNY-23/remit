🏭 Computer = A Factory

Imagine a factory where workers receive raw materials, temporarily keep them nearby, process them, and send the finished products out.

🖥️ Computer	🏭 Factory analogy	What it does
SSD / HDD	🗄️ Warehouse	Stores lots of data permanently
Data / Files	📦 Boxes in warehouse	The actual information
RAM (DRAM)	🏗️ Work area / workbench	Holds things currently being worked on
CPU	👷 Worker	Performs the actual processing
Control Unit (CU)	📋 Supervisor	Tells the worker what operation to perform
Registers	✋ Worker's hands	Holds tiny amounts of data currently being used
ALU	🧮 Calculator/tool	Performs arithmetic & logical operations
Cache	🧰 Toolbox beside the worker	Keeps frequently needed data very close
Bus	🚚 Transport system	Moves data between components
Input	📥 Incoming materials	Data coming into the computer
Output	📤 Finished products	Results produced by the computer
Program / Instructions	📋 Work instructions	Tells the factory what to do
Clock	⏱️ Factory's rhythm/timer	Coordinates operations step-by-step
Now let's actually run a program

Suppose your JavaScript program says:

10 + 20

The process is roughly:

🗄️ SSD
   │
   │  Program is loaded
   ▼
🏗️ RAM
   │
   │  CPU fetches instructions/data
   ▼
👷 CPU
   │
   ├── 📋 Control Unit
   │       "We need to perform ADD"
   │
   ├── ✋ Registers
   │       R1 = 10
   │       R2 = 20
   │
   └── 🧮 ALU
           10 + 20
              ↓
             30
              │
              ▼
          ✋ Register
           R3 = 30

Then the result might eventually go back to RAM and ultimately be displayed as output.
