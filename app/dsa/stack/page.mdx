# Stack

A collection of reusable stack templates used to solve most stack interview problems.

---

# 1. Create a Stack

```js
const stack = [];
```

---

# 2. Push

```js
stack.push(x);
```

---

# 3. Pop

```js
const top = stack.pop();
```

---

# 4. Peek (Top Element)

```js
const top = stack[stack.length - 1];
```

# 5. Check Empty

```js
if (stack.length === 0) {
    // stack is empty

```

# 6. Stack Size

```js
const size = stack.length;
```

# 8. Push All Elements


# 9. Pop Until Condition

```js
while (stack.length && stack[stack.length - 1] > x) {
    stack.pop();
}
```

**Used in**

- Remove K Digits
- Monotonic Stack
- Histogram

# 10. Pop Until Matching Character

```js
while (stack.length && stack[stack.length - 1] !== '(') {
    stack.pop();
}
```

**Used in**

- Valid Parentheses
- Infix Evaluation

# 11. Match Parentheses

```js
const map = {
    ')': '(',
    ']': '[',
    '}': '{'
};

if (
    stack.length &&
    stack[stack.length - 1] === map[ch]
) {
    stack.pop();
}
```

# 12. Reverse Using Stack

```js
for (const x of arr)
    stack.push(x);

while (stack.length)
    console.log(stack.pop());
```

# 15. Monotonic Increasing Stack

Keep stack increasing.

```js
while (
    stack.length &&
    stack[stack.length - 1] > x
) {
    stack.pop();
}

stack.push(x);
```

# 17. Next Greater Element Template

```js
for (let i = 0; i < nums.length; i++) {

    while (
        stack.length &&
        nums[stack[stack.length - 1]] < nums[i]
    ) {
        const index = stack.pop();
        ans[index] = nums[i];
    }

    stack.push(i);
}
```

# 18. Previous Greater Element

```js
for (let i = 0; i < nums.length; i++) {

    while (
        stack.length &&
        stack[stack.length - 1] <= nums[i]
    ) {
        stack.pop();
    }

    if (stack.length)
        console.log(stack[stack.length - 1]);

    stack.push(nums[i]);
}
```

# 19. Previous Smaller Element

# 20. Next Smaller Element

```js
for (let i = nums.length - 1; i >= 0; i--) {

    while (
        stack.length &&
        stack[stack.length - 1] >= nums[i]
    ) {
        stack.pop();
    }

    stack.push(nums[i]);
}
```

# 21. Largest Rectangle in Histogram Pattern

```js
let ans = 0;
const stack = [];

for (let i = 0; i <= heights.length; i++) {

    while (
        stack.length &&
        (i === heights.length ||
         heights[stack[stack.length - 1]] > heights[i])
    ) {

        const h = heights[stack.pop()];

        const w = stack.length
            ? i - stack[stack.length - 1] - 1
            : i;

        ans = Math.max(ans, h * w);
    }

    stack.push(i);
}
```

# 22. Remove Consecutive Duplicates

```js
for (const ch of s) {

    if (
        stack.length &&
        stack[stack.length - 1] === ch
    ) {
        stack.pop();
    } else {
        stack.push(ch);
    }

}
```

# 27. Min Stack Trick

Using a variable:


```js

    Math.min(x, minStack[minStack.length - 1])
```
