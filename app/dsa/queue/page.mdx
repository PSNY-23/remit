# Queue

A collection of reusable queue templates used to solve most queue and BFS interview problems.

---

# 1. Create a Queue

```js
const queue = [];
```

---

# 2. Enqueue (Insert)

```js
queue.push(x);
```

---

# 3. Dequeue (Remove Front)

```js
const front = queue.shift();
```

> Note: `shift()` is **O(n)** in JavaScript arrays. For interviews it's acceptable unless performance is critical.

---

# 4. Peek Front

```js
const front = queue[0];
```

---

# 5. Peek Rear

```js
const rear = queue[queue.length - 1];
```

---

# 6. Check if Queue is Empty

```js
if (queue.length === 0) {
    // queue is empty
}
```

---

# 7. Queue Size

```js
const size = queue.length;
```

---

# 8. Process Entire Queue

```js
while (queue.length) {
    const node = queue.shift();

    // Process node
}
```

---

# 9. Level Order Traversal (BFS)

```js
while (queue.length) {

    const size = queue.length;

    for (let i = 0; i < size; i++) {

        const node = queue.shift();

        // Process node

    }

}
```

Used in:

- Binary Tree Level Order
- Zigzag Traversal
- Minimum Depth
- BFS Problems

---

# 10. Push Multiple Nodes

```js
queue.push(left);
queue.push(right);
```

---

# 11. Push If Exists

```js
if (node.left)
    queue.push(node.left);

if (node.right)
    queue.push(node.right);
```

---

# 12. BFS on Graph

```js
queue.push(start);

while (queue.length) {

    const node = queue.shift();

    for (const nei of graph[node]) {

        queue.push(nei);

    }

}
```

---

# 13. BFS with Visited

```js
const visited = new Set();

queue.push(start);
visited.add(start);

while (queue.length) {

    const node = queue.shift();

    for (const nei of graph[node]) {

        if (!visited.has(nei)) {

            visited.add(nei);

            queue.push(nei);

        }

    }

}
```

---

# 14. Multi-Source BFS

```js
for (const node of sources) {
    queue.push(node);
}
```

Used in:

- Rotten Oranges
- Walls and Gates
- 01 Matrix

# 18. Count Levels

```js
let level = 0;

while (queue.length) {

    let size = queue.length;

    while (size--) {

        const node = queue.shift();

    }

    level++;

}
```

# 27. Queue Using Two Stacks

Enqueue

```js
stack1.push(x);
```

Dequeue

```js
while (stack1.length) {

    stack2.push(stack1.pop());

}

const item = stack2.pop();
```

# 31. Monotonic Queue (Maximum)

```js

    deque.length &&
    deque[deque.length - 1] < x
```

# 39. Master BFS Template

```js
const queue = [];

queue.push(start);

while (queue.length) {

    const node = queue.shift();

    // Process

    for (const nei of graph[node]) {

        queue.push(nei);

    }

}
```

---

# 40. Master Level Order Template

```js
const queue = [root];

while (queue.length) {

    const size = queue.length;

    for (let i = 0; i < size; i++) {

        const node = queue.shift();

        // Process node

        if (node.left)
            queue.push(node.left);

        if (node.right)
            queue.push(node.right);

    }

}
```
