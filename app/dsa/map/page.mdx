# Map

A collection of reusable **Map/HashMap** templates used to solve most interview problems involving frequency counting, lookups, grouping, caching, and indexing.

> **Tip:** In JavaScript interviews, prefer `Map` over plain objects (`{}`) because it supports any key type and avoids prototype-related issues.

# 8. Increment Frequency


# 19. Store Index


# 20. Lookup Index


# 21. Two Sum Template

```js
const map = new Map();

for (let i = 0; i < nums.length; i++) {

    const need = target - nums[i];

    if (map.has(need)) {

        return [map.get(need), i];

    }

    map.set(nums[i], i);

}
```

# 22. Group Values

```js
if (!map.has(key)) {

    map.set(key, []);

}

map.get(key).push(value);
```

Used in:

- Group Anagrams
- Group Employees
- Group Words

# 34. Maximum Frequency

```js

    maxFreq = Math.max(maxFreq, count);

}
```

---

# 35. Minimum Frequency

```js
let minFreq = Infinity;

for (const count of map.values()) {

    minFreq = Math.min(minFreq, count);

}
```

---

# 36. Find Key with Maximum Value

```js
let ans = null;
let best = -Infinity;

for (const [key, value] of map) {

    if (value > best) {

        best = value;
        ans = key;

    }

}
```
