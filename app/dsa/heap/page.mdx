# Heap

A collection of reusable **Heap / Priority Queue** templates used to solve most interview problems.

> **Note:** JavaScript doesn't have a built-in Priority Queue. In interviews (especially on LeetCode), you'll often use `MaxPriorityQueue` and `MinPriorityQueue` if they're available, or implement your own heap.

---


# 11. K Smallest Elements

```js

    maxHeap.enqueue(num);
```

# 13. Top K Frequent Elements

```js

    minHeap.enqueue(

        minHeap.dequeue();

    }

}
```

# 21. Balance Two Heaps

```js

    left.size() >
    right.size() + 1
) {

    right.enqueue(
        left.dequeue().element
    );

}
```

# 26. Update Neighbor

```js
if (
    dist + weight <
    distance[next]
) {

    distance[next] =
        dist + weight;

    minHeap.enqueue(
        [distance[next], next],
        distance[next]
    );

}
```
