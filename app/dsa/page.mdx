# Overview

A comprehensive collection of reusable patterns, templates, and code snippets in JavaScript for technical interviews.

## Topics

- [Graph](/dsa/graph) - Adjacency lists, DFS, BFS, Dijkstra, Topological Sort, Union-Find
- [Heap / Priority Queue](/dsa/heap) - Min/Max heaps, Top K elements, Two Heaps, Dijkstra
- [HashMap / Map](/dsa/map) - Frequency counting, index lookups, grouping, caching
- [Queue](/dsa/queue) - BFS, Level order traversal, Multi-source BFS, Monotonic queue
- [Set](/dsa/set) - Deduplication, membership testing, union, intersection
- [Stack](/dsa/stack) - Monotonic stack, parentheses matching, histogram, DFS
- [Binary Tree](/dsa/tree) - DFS/BFS traversals, BST operations, diameter, LCA, views
