# Flexbox vs CSS Grid


- **Flexbox (1D):** Row *or* column. Perfect for navigation menus, button groups, vertical centering.
- **Grid (2D):** Rows *and* columns simultaneously. Perfect for whole-page layouts, card galleries, dashboards.
