# Web Accessibility (a11y)

### Core Principles of Accessibility
1. **Perceivable:** Information must be presentable to users in ways they can perceive (e.g. `alt` text on images, sufficient color contrast).
2. **Operable:** UI components and navigation must be operable via keyboard (`tabindex="0"`, visible focus rings).
3. **Understandable:** Content and operation must be clear and predictable.
4. **Robust:** Content must be robust enough to be interpreted by screen readers and assistive technologies.
