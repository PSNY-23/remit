# any vs unknown vs never

- **`any`:** Unchecked escape hatch. Disables type safety.
- **`unknown`:** Type-safe counterpart. Must be narrowed with type guards before use.
- **`never`:** Bottom type. Represents code paths that cannot occur (empty set).
