# CSS Specificity


Specificity weight score:
- **Inline Styles:** `1-0-0-0`
- **IDs:** `0-1-0-0`
- **Classes, Attributes, Pseudo-classes:** `0-0-1-0`
- **Elements, Pseudo-elements:** `0-0-0-1`
