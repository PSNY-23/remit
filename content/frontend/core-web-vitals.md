# Core Web Vitals (CWV)

- **Largest Contentful Paint (LCP) < 2.5s:** Measures perceived loading speed of main content.
- **Interaction to Next Paint (INP) < 200ms:** Measures UI responsiveness to user interactions.
- **Cumulative Layout Shift (CLS) < 0.1:** Measures visual stability and unexpected layout shifts.
