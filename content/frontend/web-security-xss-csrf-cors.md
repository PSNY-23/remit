# Web Security: XSS, CSRF & CORS


- **XSS (Cross-Site Scripting):** Injecting malicious JS. *Defense: Input sanitization, CSP, HttpOnly cookies.*
- **CSRF (Cross-Site Request Forgery):** Forging unauthorized requests. *Defense: SameSite cookies, CSRF tokens.*
- **CORS:** Browser policy restricting cross-origin requests. Configured on the API server.
