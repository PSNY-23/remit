# Reference vs Primitive Types


- **Primitive Types:** `number`, `string`, `boolean`, `null`, `undefined`, `symbol`, `bigint`. Stored by value on the stack.
- **Reference Types:** `Object`, `Array`, `Function`, `Map`, `Set`. Stored by reference on the heap.
